## 一、五条规范原文（逐字录入）

**【命名规范补充说明】**

1. **根目录命名格式**：`"学校全称-队长姓名-作品名称"`，中间用**半角连字符**分隔。
   示例：`南京大学-张三-区块链 XXX 应用开发`

2. **子文件夹名称统一使用两位数字序号**：`01_作品文件`、`02_作品展示`、`03_设计文档`、`04_作品信息`、`05_承诺书`、`06_源文件`。

3. **文件夹内文件命名格式**：`"作品名称_文件描述.扩展名"`。
   示例：`区块链 XXX 应用开发_演示视频.mp4`

4. **PDF 文档建议生成 PDF/A-1b 格式**，确保评审系统兼容显示。

5. **`06_源文件`夹中，各分类专项材料按材料类型建立二级子文件夹归类**，例如：
   `06_源文件/技术路线图/`、`06_源文件/02_效果图/`、`06_源文件/03_源代码/`。
